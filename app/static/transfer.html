다른 PC로 자료 옮기기

양식과 작업을 파일로 주고받아 이어서 처리할 수 있습니다. 여러 PC에 페이지를 나눠 맡긴 뒤 결과를 다시 합칠 수도 있습니다.

저장된 자료를 .hscan 파일로 옮깁니다. 작업에 필요한 양식은 함께 포함하며, 모델은 받는 PC에서 설치합니다.

페이지를 나눠 처리하려면

  1. 내보내기에서 작업 하나를 고르고 페이지 분담을 선택하세요.
  2. 맡길 페이지를 고르면 이 PC는 해당 페이지를 건너뛰고 나머지를 처리합니다.
  3. 다른 PC에서 파일을 불러와 이어하기로 처리한 뒤, 작업을 다시 내보내세요.
  4. 돌아온 파일을 불러와 기존 작업과 합치기를 누르세요. 원본을 보존한 새 통합 작업이 만들어집니다.

파일 전달을 취소하거나 이 PC에서 다시 처리하려면 내보내기 화면에서 ‘분담 해제’를 누르세요.
