handwrite-scanner

프린트된 양식에 손으로 작성한 문서를 사진으로 찍어 올리면, 내용을 텍스트로 인식해 검색 가능한 PDF와 표(엑셀용 CSV 등)로 만들어 주는 프로그램입니다. 모든 처리가 회사 PC 안에서 이루어지며 문서가 외부로 전송되지 않습니다.

1설치와 실행

설치 위치 정하기 (먼저 읽어주세요)

이 프로그램은 압축 푼 폴더 하나가 곧 설치 전체인 포터블 방식입니다. 실행하면 프로그램 옆에 인식 엔진(engine\, 약 6GB)과 작업 데이터(data\ — 템플릿·작업 기록·결과)가 함께 만들어집니다. 그래서 폴더 위치가 중요합니다.

  • 디스크 여유가 8GB 이상인 드라이브에 두세요 — 첫 실행 때 인식 엔진 약 6GB를 내려받고, 이후 작업 데이터도 계속 쌓이기 때문입니다.
  • C:\Program Files 안에는 두지 마세요 — Windows가 그 안의 쓰기를 관리자 권한으로 제한하기 때문에, 일반 실행으로는 엔진 다운로드와 작업 저장이 실패합니다. D:\handwrite-scanner나 C:\Users\이름\ 아래처럼 내가 자유롭게 쓸 수 있는 위치가 적합합니다.
  • 이동·백업은 폴더째로 — 폴더를 통째로 복사하면 모델·템플릿·작업 기록까지 전부 따라가므로 다른 PC에서 재다운로드 없이 바로 쓸 수 있습니다. 반대로 handwrite-scanner.exe만 따로 복사하면 실행되지 않습니다 (_internal\에 프로그램 구성 요소가 들어 있습니다).
  • 삭제 시 주의 — 폴더를 지우면 작업 기록도 함께 사라집니다. 기록을 남기려면 data\ 폴더만 다른 곳에 복사해 두세요.

내 PC에서만 쓸 때

  1. 배포 파일 handwrite-scanner.zip을 원하는 폴더에 풉니다. (별도 프로그램 설치 불필요)
  2. handwrite-scanner.exe를 실행합니다. 잠시 후 브라우저가 자동으로 열립니다.
  3. 첫 실행에만 인식 엔진(약 6GB)을 자동으로 내려받습니다. 검은 창에 진행률이 표시되며, 완료까지 회선에 따라 수십 분 걸릴 수 있습니다. 두 번째 실행부터는 바로 켜집니다.

사무실에서 여럿이 쓸 때 (서버 방식)

  1. PC 한 대(램 16GB 권장)에만 위와 같이 설치하고, server-mode.bat을 실행합니다.
  2. 검은 창에 표시되는 주소(예: http://192.168.0.10:8000)를 다른 직원들에게 알려줍니다. 각자 브라우저 주소창에 입력하면 바로 사용할 수 있습니다.
  3. 처음 켤 때 Windows 방화벽 허용 창이 뜨면 허용을 누릅니다.

업데이트하기

새 버전이 나오면 앱 화면 상단에 배너로 안내됩니다. 업데이트 절차:

  1. 프로그램(검은 콘솔 창)을 종료합니다.
  2. 새 zip을 기존 폴더에 통째로 풀어 덮어씁니다 — exe와 _internal\(프로그램 본체), server-mode.bat이 함께 교체됩니다. exe만 바꾸면 안 됩니다 — 프로그램 본체와 화면 파일이 _internal\에 들어 있기 때문입니다.
  3. engine\(모델)과 data\(작업 기록)는 zip에 없으므로 그대로 유지됩니다 — 재다운로드나 백업이 필요 없습니다.

업데이트 후 이상 동작하면: _internal\ 폴더와 exe만 지우고 (engine·data는 그대로 두고) 새 zip을 다시 풀면 확실하게 정리됩니다.

요구 사양 램 16GB 권장(8GB 이하는 경량 모델 선택 — 아래 참고), 디스크 여유 8GB 이상. GPU는 필요 없습니다. 프로그램을 끝내려면 검은 콘솔 창을 닫으면 됩니다.

인식 모델 선택

작업 화면의 인식 모델 카드에서 PC 사양에 맞는 모델을 고를 수 있습니다. 초경량(2B, 램 4GB)부터 고성능(30B, 램 32GB)까지 있고, 이 PC의 RAM 기준 추천 모델에 ⭐ 표시가 붙습니다. 첫 설치 때도 사양에 맞는 모델이 자동 선택됩니다. 미설치 모델은 다운로드 버튼으로 받고(진행률 표시), 설치된 모델은 사용 버튼으로 전환합니다 — 다음 인식부터 적용됩니다. 모델이 클수록 정확하고, 작을수록 빠르고 가볍습니다.

2템플릿 만들기 — 인식률의 핵심 (양식마다 1회, 관리자)

템플릿은 "이 양식의 어느 위치에 어떤 종류의 값이 적히는지"를 알려주는 설정입니다. 템플릿 없이도 인식은 되지만, 등록하면 정확도가 크게 올라갑니다. 자주 쓰는 양식일수록 꼭 등록하세요.

  1. 상단 메뉴 템플릿 → 이름 입력 → 빈 양식(아무것도 안 적힌 원본)의 이미지나 PDF를 선택하고 기준 양식 등록.
  2. 화면에 뜬 양식 이미지 위에서 마우스 드래그로 손글씨가 적힐 칸마다 박스를 그립니다. 칸 테두리에 다소 걸쳐도 괜찮습니다.
  3. 아래 표에서 각 박스의 라벨(이름)과 타입을 지정하고 저장.
타입어떤 칸에 쓰나예시
자유텍스트아무 내용이나 적히는 칸사유, 비고
후보목록정해진 값 중 하나가 적히는 칸. 후보를 줄바꿈으로 입력해 두면 가장 비슷한 것을 자동 선택성명(직원 명단), 부서명
전화번호전화번호 칸. 자릿수 검증과 형식 정리를 자동 수행연락처
숫자숫자만 적히는 칸. 범위(min~max)를 지정하면 잘못 읽은 값을 자동으로 걸러냄월차잔여수 (0~11)
표시 선택인쇄된 선택지 중 하나에 동그라미·체크·빗금 등이 표시되는 칸. 선택지를 후보 목록에 입력승인종류
인식률을 올리는 요령 후보목록과 숫자 범위를 최대한 채워 두세요. "적힐 수 있는 값"을 좁혀 줄수록 악필도 정확히 읽어냅니다. 특수한 칸은 추가 지시란에 설명을 적어줄 수 있습니다 (예: "인쇄된 20과 손글씨를 이어붙여 연도로 읽어라").

더 편하게 만드는 기능

  • ✨ 자동 필드 감지 (베타) — 버튼 하나로 입력란과 라벨을 자동으로 찾아 필드 초안을 만들어 줍니다. 위치와 타입만 다듬고 저장하면 됩니다.
  • 검증 규칙 — 필드 id를 변수로 쓰는 식(예: pre - post >= 0)을 등록하면, 계산이 안 맞는 문서를 검수에서 자동으로 강조해 줍니다.
  • 후보목록 자동 학습 — 검수에서 값을 고치면 "후보목록에 추가" 버튼이 나타나 한 번의 클릭으로 다음부터 그 값을 인식하게 됩니다.

3문서 인식하기

  1. 작업 화면에서 문서 사진이나 복합기 스캔 PDF(여러 장짜리도 페이지별로 자동 분해)를 선택하고 인식 시작. 템플릿은 기본값 (자동 판별)로 두면 페이지마다 어떤 양식인지 스스로 찾아내므로, 여러 양식이 섞인 뭉치도 한 번에 올릴 수 있습니다.
  2. 📱 폰으로 촬영 업로드 버튼을 누르면 QR 코드가 뜹니다. 같은 Wi-Fi의 휴대폰으로 찍으면 폰 카메라로 촬영해 바로 올릴 수 있습니다. 창을 닫으면 연결이 다시 차단되어 평소엔 완전 로컬 상태를 유지합니다.
  3. 작업 목록에 진행률이 표시됩니다. 문서 1장에 수 분 정도 걸리므로, 여러 장을 한 번에 걸어두고 다른 일을 하다가 나중에 검수하는 방식을 권합니다. 퇴근 전에 걸어두면 다음날 아침 완료되어 있습니다.
  4. 같은 양식의 문서끼리 한 작업으로 올리세요. 한 작업의 모든 사진에 같은 템플릿이 적용되고, PDF도 작업 단위로 한 파일이 됩니다.

사진은 스캐너가 아니어도 됩니다. 휴대폰 사진도 문서가 화면에 꽉 차고 초점이 맞으면 기울어짐은 자동으로 보정됩니다.

4검수 — 색만 보면 됩니다

작업이 끝나면 검수/다운로드를 엽니다. 필드마다 원본 손글씨 조각과 인식된 텍스트가 나란히 표시되고, 행 색깔이 확신도를 나타냅니다.

색의미할 일
초록 (100%) 후보와 정확히 일치넘어가도 됨
노랑 (76~99%) 형식 검증 통과훑어보기
주황 (51~75%) 확신 낮음 · 자동 보정됨원본과 대조
빨강 (50% 이하) 인식 실패 가능성반드시 확인

값이 틀렸으면 입력란을 클릭해 고치면 됩니다. 고치는 즉시 저장되고 해당 행은 초록으로 바뀝니다. 브라우저를 닫았다 다시 열어도 수정 내용은 유지됩니다.

5결과 받기

  • 미리보기 — 다운로드 없이 브라우저 탭에서 PDF를 바로 확인합니다.
  • PDF 다운로드 (원본+텍스트층) — 보기엔 스캔본 그대로이면서, 안의 글자를 검색·복사할 수 있는 PDF입니다. 인식된 텍스트가 각 칸 아래 흐린 회색으로 표시됩니다.
  • 표 내보내기 — 드롭다운에서 형식을 고르고 내려받습니다.
    • CSV — 엑셀용. 같은 양식 여러 장이면 문서 1장 = 1행으로 나와 바로 집계 가능
    • Markdown / 텍스트 — 보고서·메일에 붙여넣기 좋은 표 형식
  • 통합 내보내기 — 작업 화면에서 양식을 고르면, 그 양식으로 처리한 모든 작업의 문서 전체를 하나의 표(작업ID·처리일시 포함)로 모아 내려받습니다. 누적 대장 용도.
  • 문서 검색 — 작업 화면 검색창에 이름 등을 입력하면 과거에 인식한 모든 문서에서 찾아 해당 검수 화면으로 바로 이동합니다.

6문제 해결

증상원인과 해결
내려받은 PDF를 열 때 "위험할 수 있음" 경고 웹에서 받은 모든 파일에 붙는 Windows 표식으로, 파일에는 문제가 없습니다. 확인만 할 땐 미리보기를 쓰면 경고가 없습니다. 파일 우클릭 → 속성 → 차단 해제로 없앨 수도 있습니다.
다른 PC에서 서버 주소로 접속이 안 됨 서버 PC에서 방화벽 허용을 안 했을 가능성. server-mode.bat을 다시 실행해 허용 창에서 허용을 누르세요.
검수 화면에 "정합 실패" 경고 사진이 심하게 비뚤거나 다른 양식일 때 표시됩니다. 결과를 꼼꼼히 확인하고, 가능하면 문서가 정면으로 나오게 다시 찍어 올리세요.
처리가 너무 느리거나 멈춤 정상적으로 1장에 수 분입니다. 콘솔 창에 오류가 보이거나 램 부족이면 관리자에게 경량(3B) 모델 설정을 요청하세요.
작업 기록을 백업하고 싶음 프로그램 폴더의 data\ 폴더에 템플릿과 모든 작업 (원본·결과·PDF)이 저장됩니다. 이 폴더만 복사하면 전체 백업이 됩니다.
