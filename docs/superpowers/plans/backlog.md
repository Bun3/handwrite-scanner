# 백로그

구현 전 아이디어 보관소. 착수 시 항목별로 계획 문서로 승격.

## 외부 AI 2차 판독 (하이브리드) — 2026-08-26 논의

로컬 8B가 확신하지 못한 필드만 외부 프론티어 모델(Claude/GPT/Gemini API)로
재판독해 인식률을 끌어올리는 옵션 기능.

**배경**
- 실전 136페이지 비교 테스트 결과, 흘림 글씨 일부는 로컬 8B/30B 모두 "능력
  경계선" 위에 있음 (같은 크롭도 배율 따라 판독이 뒤집힘). 30B(MoE, 활성 3B)는
  8B보다 오히려 열세 → 로컬 모델 증량은 해법이 아님.
- 프론티어 모델이면 이 경계선 케이스 대부분 해소 예상. 남은 판독률 격차를
  좁히는 가장 확실한 수단.

**전제 조건 (선결)**
- 회사 정책상 문서(또는 필드 크롭)의 외부 API 반출 허용 여부 확인.
  개인정보(성명·사유 등) 포함이므로 정책 결정이 우선.

**설계 방향**
- 기본 꺼짐. 설정 카드 "외부 AI 2차 판독 (선택, API 키 필요)" + 켤 때 반출 경고.
- 노출 최소화: 전체 문서가 아니라 **저신뢰(빨간색) 필드의 크롭만** 전송.
  136페이지 기준 294필드 중 한 자릿수만 외부로 나가는 규모.
- 키 관리는 **조직 키 1개** 방식 권장: 관리자가 서버(모드) PC에 키 한 번 입력,
  일반 사용자는 API·과금의 존재를 모름. 월 비용은 크롭 단가(1~2원 미만)라 미미,
  API 콘솔 지출 한도로 폭주 방지.
- 개인·소규모용 대안: Gemini API 무료 티어(카드 등록 불필요, 분당 제한은
  배치 특성상 무관).
- 채팅 구독(ChatGPT Plus, Claude Pro)을 프로그램에서 끌어 쓰는 건 미지원 —
  API가 정도.
- 구현 접점: 모든 추론이 `llm.ask_image` 한 관문을 지나므로 백엔드 분기만 추가.

## 중첩(부모-자식) 필드 인식 — 2026-08-27 논의

넓은 부모 박스(예: 날짜 전체 문장)를 한 번 읽어 참고용으로 두고, 세부 자식
필드(월/일/시간)를 별도로 읽는 방식.
- **겹치는 박스 자체는 지금도 가능** — 부모를 text 필드로 그리면 추가 인식되어
  검수에서 참고 가능 (+페이지당 LLM 1회).
- 자동 교차검증(부모 텍스트 ↔ 자식 숫자 일치)은 텍스트 파싱이 필요해 현재
  숫자 전용 규칙 엔진 밖 — 필요성이 확인되면 "부모에서 자식 값 추출" LLM
  재질문 형태로 설계.

## 기각된 실험 (재논의 방지용 기록)

- **확대 배율 재질문** (2026-08-26): 같은 crop이 배율마다 다른 후보를 확신 있게
  내놓음(1.15x=없음/2x=이순덕/2.3x=이관희) → 그럴듯한 오답 생성 위험으로 기각.
- **템플릿 인쇄선 제거 전처리** (2026-08-27): 기준 이미지의 어두운 픽셀을 지운
  깨끗한 crop으로도 판독 결과 불변(p3 없음, p38 강태현) → 원인은 선이 아니라
  흘림 글씨 자체로 확인, 기각.

## 기타 후보 (그때그때 언급된 것)

- **날짜(기간) 필드 쪼개기 안내**: 인쇄 문구가 섞인 넓은 기간 칸은 빈칸별
  number 필드(min/max)로 나누는 게 정석 — 가이드/템플릿 편집기에서 유도하는 UX.
- **circle 미표시 환각 방어**: 아무 표시 없는 선택지 칸에서 모델이 답을 지어내는
  케이스(p121) — 미표시 감지 휴리스틱 또는 재질문.
- 핫폴더 감시(폴더에 넣으면 자동 인식), 작업 보존 기간 정책, 검수 통계 대시보드.
