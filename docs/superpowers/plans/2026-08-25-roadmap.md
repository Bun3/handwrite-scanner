# v0.3 로드맵 구현 계획

전제: 모든 양식은 1장짜리 (사용자 확정). 진행 순서 = 아래 나열 순서.
각 항목은 독립 커밋 + 검증 후 다음으로.

## 1차 — 입력 파이프라인

### F7. PDF 업로드
- `jobs.create()`에서 PDF 파일이면 pymupdf로 300dpi 페이지 이미지로 분해해 input/에 저장
  (워커·검수·PDF 생성은 무수정 — 페이지 수만 늘어남). 이미지·PDF 혼합 업로드 허용
- `index.html` accept에 `.pdf` 추가
- 검증: dummy-form.pdf 업로드 → input에 png 생성 단위 테스트

### F1. 양식 자동 판별
- `align._orb_align`이 (정합 이미지, 인라이어 점수) 반환하도록 확장
- 워커: 템플릿 미지정 시 **페이지마다** 전 템플릿과 대조, 최고 점수 ≥ 임계값(40)이면 채택,
  아니면 기존 freeform 폴백. results 페이지에 `template` 기록
- UI: 템플릿 선택 기본값을 "(자동 판별)"로, 검수 화면에 페이지별 판별 결과 표시
- clean PDF는 페이지별 template 사용
- 검증: 더미 작성본을 템플릿 미지정 업로드 → dummy-vacation 판별 E2E

### F5. 폰 촬영 업로드 (단독 모드 포함)
- "폰 업로드" 버튼 → 1회용 토큰 발급 + **0.0.0.0 바인드 보조 리스너**(uvicorn 스레드, 포트 8001)
  기동 → QR(내부IP:8001/p/<토큰>) 모달 표시. 닫으면 리스너 종료 = 다시 완전 로컬
- 폰 페이지: 모바일 최소 UI (카메라 촬영 input + 업로드 → 자동 판별 작업 생성)
- 서버 모드(--server)에서는 이미 열려 있으므로 같은 포트로 QR만 표시
- 의존성 추가: `qrcode` (QR 생성, 순수 파이썬)
- 검증: 토큰 없는 접근 거부, 토큰 접근 업로드 → 작업 생성

## 2차 — 인식 개선

### F2. 후보목록 자동 학습
- 검수 PATCH에서 수정값이 후보 타입인데 목록에 없으면 응답에 `suggest` 플래그
- 검수 UI: "후보목록에 '값' 추가" 인라인 버튼 → POST `/api/templates/{name}/candidates`
- 검증: 단위 테스트(목록 추가·중복 방지)

### F4. 교차 필드 검증 규칙
- template.json에 `rules: ["pre - post >= 0", ...]` (필드 id 변수, 정수 산술·비교만)
- ast 기반 화이트리스트 미니 평가기 (eval 금지)
- 워커: 페이지 인식 후 규칙 평가 → 실패 시 관련 필드 confidence 0.5로 강하 + 페이지 경고
- 편집기: 규칙 입력란(줄바꿈 구분), 검수: 경고 배너
- 검증: 평가기 단위 테스트(허용식·금지식), 규칙 실패 시 신뢰도 강하

### F3. 자동 필드 감지 (베타)
- 편집기 "자동 감지" 버튼 → POST `/api/templates/{name}/autodetect`
- VLM에 기준 이미지 + "입력란들을 label/bbox(0~1000 상대좌표) JSON으로" 프롬프트 →
  픽셀 좌표 변환 → 필드 초안 반환, 편집기에 로드(사람이 조정 후 저장)
- 좌표 정확도는 실험으로 확인, 부정확하면 '초안'임을 UI에 명시
- 검증: 더미 양식에서 5개 필드 근사 감지 확인

## 3차 — 결과 활용

### F8. 통합 내보내기 (머지)
- GET `/api/export-merged?template=X&fmt=md|txt|csv` — 해당 템플릿의 완료 작업 전체를
  기존 export 형식 그대로 병합. CSV는 문서 1장=1행 + `작업ID`·`처리일시` 열 추가
- index에 "통합 내보내기" 카드(템플릿+형식 선택)
- 검증: 두 작업 병합 단위 테스트

### F9. 문서 검색
- GET `/api/search?q=` — 전 작업 results.json 부분 문자열 검색(파일 스캔, 수백 건 규모 충분)
  → [{job, page, label, value}] 반환
- index 상단 검색창 → 결과 클릭 시 해당 검수 화면으로 이동
- 검증: 단위 테스트
